# The Shadowglitch Crew — Companion Website

The public, child-friendly companion website for **The Shadowglitch Crew — Volume 1: The HQ Blackout**, an illustrated cybersecurity activity-book series for readers in Grades 3–6.

## Website
Planned live address: **https://shadowglitch-crew.github.io/**

- `index.html`: responsive public landing page linking all three optional online games.
- `training/mission003/index.html`: no-login fictional password-vault challenge (no real passwords).\n- `training/mission009/index.html`: self-contained, no-sign-in safe View Source challenge.\n- `training/mission011/index.html`: fictional backup-recovery finale, with spoiler warning.
- `assets/cipher.jpg` and `assets/nyx.jpg`: original character portraits used on the homepage.
- **Current publication stage:** homepage and all three browser training games are public. Collectible PDFs and the private book manuscripts, print files, and answer keys are **not** published.

## GitHub Pages publishing

A repository owner must enable GitHub Pages in **Settings → Pages → Build and deployment → Deploy from a branch**, select **main** and **/(root)**, then save. The source is the top-level `index.html`.

A first deployment may take a few minutes. Once live, check the address above on a mobile phone before printing QR codes.

## Safeguards

- Keep unpublished book manuscripts, answer keys, and KDP print files exclusively in the private `shadowglitch-crew-production` repository.
- No email forms, sign-ins, comments, behavioural analytics, advertising, or personal-data collection.
- The self-contained Mission 003, 009 and 011 games are public under `training/`; they use fictional or approved practice content only, never real credentials or unauthorized targets. Approve each collectible before publishing it.
- Teach ethical cybersecurity: only explore or test practice systems with permission.
- The book is in development; the public page does not claim it is already for sale.

## Updating

Edit and push `index.html`, then allow GitHub Pages to redeploy. QR codes can continue to point to the stable homepage even when bonus materials change.
